HOW IT WORKS

Live Sleeper trade history

This site reads public league data from Sleeper in your browser. It follows the league's previous-season chain, loads completed trades, and turns the assets received in a selected deal into a traceable lineage.

Player data is cached locally in the browser to reduce calls to Sleeper's larger player directory endpoint. No login or API key is required.
